# 🎬 AI Video, Typography & Human Voiceover Integration Guide

This guide explains how **clean cinematic video**, **crystal-clear vector typography**, **human-like emotional voiceovers**, **ElevenLabs**, and **Google Flow AI** work in this project.

---

## 1. Why Text Looked Like "AI" & How It Is Solved

### The Problem:
When titles, text, or subtitles are encoded directly into video frames (pixels) and compressed with H.264 or generated by video AI, **compression block artifacts (DCT ringing) and chroma subsampling blur the fonts**, making characters look like garbled AI artifacts or unreadable glyphs.

### The Netflix / Apple TV Architecture (Implemented):
1. **Clean Video Canvas**: The background `.mp4` video footage contains **zero rasterized text**. It consists solely of pristine, high-definition historical documentary footage with smooth Ken Burns cinematic camera motion (pans, zooms, film grading).
2. **Native Vector DOM Overlay**: All titles, milestone badges, chapter indicators, specs, and Closed Caption (CC) subtitles are rendered by the browser as **live CSS vector elements** using Google Fonts (Outfit, Inter, Nirmala UI) on glassmorphism panels.
3. **Result**: 
   - **100% crisp typography** on 4K, Retina, 1080p, and mobile screens.
   - Zero compression blur.
   - Text can be selected, searched, read by screen readers, and instantly switched between Marathi and English.

## 3. How to Connect ElevenLabs (Optional Custom Voices)

If you want to use **ElevenLabs** for custom cloned voices or specific voice IDs:

### Step 1: Set Your ElevenLabs API Key
In PowerShell:
```powershell
$env:ELEVENLABS_API_KEY="your_elevenlabs_api_key_here"
```

### Step 2: Run the Voice Generator
Generate all 5 generations or a specific generation:
```powershell
python scripts/generate_with_elevenlabs.py
```
To generate only Generation 1 in English:
```powershell
python scripts/generate_with_elevenlabs.py --gen 1 --lang en
```
To use a custom voice clone ID:
```powershell
python scripts/generate_with_elevenlabs.py --voice "your_custom_voice_id"
```
The script will directly replace `assets/audio/gen{X}_{lang}.mp3` with your ElevenLabs voiceover!

## 4. How to Connect Google Flow AI / Gemini API

If you want to use **Google AI Studio / Gemini API / Google Flow AI** for generating additional visual clips:

### Step 1: Set Your Gemini API Key
In PowerShell:
```powershell
$env:GEMINI_API_KEY="your_gemini_api_key_here"
```

### Step 2: Run the Asset Generator
```powershell
python scripts/generate_with_google_flow.py
```
Or for a specific generation:
```powershell
python scripts/generate_with_google_flow.py --gen 1
```
